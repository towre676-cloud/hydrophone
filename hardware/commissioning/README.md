# Measured commissioning: writer calibration and axial boss-motion witness

**This is an executable route from actual reference readings to checked numerical records. No physical reference measurements were made here.** Work is confined to this new directory; the earlier design packet and calibration folder are unchanged. The motion tool computes a conditional bound from supplied measured phasors and error budgets. The writer tool fits installed channels and tests held-out reference levels, then deliberately produces a readout-compatible **unqualified** proposal. Neither program drives a device, purchases equipment, supplies an interlock or proves retained clay memory.

**The measured port is explicit.** The motion witness concerns the axial motion of the dry diaphragm boss at the rod center, along the M03 Y axis, about the wet equilibrium. It does not bound the maximum displacement elsewhere on the membrane. If the mechanical ceiling is intended to cover the whole membrane, obtain a spatial measurement/model witness as well; this tool rejects that interpretation instead of treating one spot as a scan. The provisional ceiling accepted by the program is at most 10 micrometres. The instrument remains a bench-commissioning assembly until the required physical evidence exists.

Run the following from the repository root with Python 3.10 or newer. These commands use assigned synthetic values only. Choose new output paths: the tools preserve earlier receipts rather than overwrite them.


The saved synthetic motion receipt bounds boss motion by approximately **6.024 micrometres** at a digital peak of 0.01, under its assigned data. Its largest supported peak in the assigned amplitude domain is approximately 0.017198. Those are test-fixture results, not recommended settings for an object. The synthetic writer checks give finite-reference-point envelopes of roughly 0.00411 N, 0.726 micrometres and 0.075 degrees Celsius for force, position and the optional temperature channel. These finite-point envelopes do not establish uniform physical accuracy. The example proposals remain blocked.

## Obtain the independent motion reference

**A concrete optional reference is a Polytec VibroGo configured with the displacement-output option**, a tripod/pan-tilt stand and the manufacturer's appropriate analog output/cable. The current primary product page confirms family operation up to 320 kHz, displacement as an additional output, analog/digital interfaces and tripod accessories. It does not establish the accuracy, decoder options or calibration of a particular rental unit. Request the actual model/decoder/range, low/high-pass settings, calibration certificate, calibrated output scale and frequency-dependent phase/error scope before relying on it. No price or availability was verified, and no rental or purchase was arranged. The primary link and its applicability limits are in `sources.json`.

Place the optical head on a rigid stand on the adjacent bench, separate from the moving instrument. Aim through the M03 optical access at the **dry boss**, as near to normal incidence along Y as the access geometry permits. Record the spot position and beam angle. A reflective target, if required, changes the surface/mass configuration and must remain identified. Record optical signal-quality and dropout/overload flags, head/stand motion, local target rotation and the installed line-of-sight projection correction. One spot does not distinguish translation from every rotational contribution; the supplied boss-axis error must include that uncertainty. A factory resolution number or decoder full-scale range is not the installed error budget.

For a common-clock phasor comparison, the commissioning configuration can temporarily replace hydrophone input IN1 with the independently calibrated LDV analog signal through an electronics-approved LINE path, retaining IN2 bridge acceleration, IN3 electrical command loopback and IN4 sync. Turn phantom off and use the actual LINE connector/path; do not connect an LDV voltage source to a phantom-powered XLR input. This is a new configuration ID, requiring its own electrical gain/phase check. If the external filter is repatched, record the exact path and settings. Leave the hydrophone physically mounted in the filled cell so that its mass/geometry need not change; only its recording path is substituted. Reconnecting the hydrophone, restoring phantom or changing conditioning requires the corresponding configuration check before using a transferred result.

Also retain a native broadband LDV recording, where supported by the actual rented configuration, to investigate components rejected by the ordinary audio path. The 2 kHz filtered UMC recording alone cannot establish motion outside that band. Record before the command starts and after the last required ringdown/quiet interval, with enough extra time to cover clock uncertainty. The qualification file names both the required time interval and the conservatively larger measured interval. It blocks if the latter does not cover the entire requested waveform, including on/off transients. The LDV's instrument band, settings and calibration must be recorded; a broad advertised family bandwidth does not fill an unseen-band error term.

Initial excitation during commissioning is an engineering trial under the mechanical/electrical owners' physical limits and an independent motion observer. Start with the amplifier muted/minimum and the lowest independently observed excitation, use the accessible physical mute/power control, and increase only under that observer. A digital starting peak is not a guaranteed first-motion ceiling. These offline programs cannot stop a resonance excursion or serve as a live displacement interlock.

## Direct boss measurement or the measured bridge shortcut

The most direct initial history experiment keeps the qualified optical observer on the boss. At each requested probe frequency, export the calibrated complex displacement phasor in metres, or calibrated velocity in metres/second, with its complete absolute complex error radius. Use the same phase origin as the other channels and a measured SI frequency/timebase. Do not put digital full-scale values into SI fields. Acceleration from the existing PCB chain also needs its installed sensor/conditioner/filter/load/ADC calibration and uncertainty; nominal mV/g cannot fill the field.

The bridge shortcut first measures the same stationary boss displacement and bridge acceleration simultaneously. With `a=-omega^2*x_bridge`, the measured displacement ratio is `R=x_boss/x_bridge=-omega^2*x_boss/a`. `motion.py --derive-transfer` computes a conditional complex R disk from those SI phasors, their disks and the frequency interval. A resolved acceleration denominator is required; a near-node bridge response is not a useful calibration point. The helper propagates the supplied denominator uncertainty and frequency interval rather than divide by an uncertain zero. Copy `transfer_input.template.json` to a new run directory, fill its actual calibrated point data and run:

```bash
python hardware/commissioning/motion.py results/transfer_run_001/transfer_input.json --configuration-id YOUR_CURRENT_CONFIGURATION --derive-transfer --output results/transfer_run_001/transfer_points.json
```

That calculation qualifies **points only**. Repeat at the intended amplitude levels, wet equilibrium, rod engagement, preload and written-state family. A calibration on the rigid dummy cannot silently stand in for R after a clay write. Either retain direct boss measurement during the experiment or establish a conservative R envelope covering every intended state and record its evidence. The motion record's transfer-domain flag is a declaration backed by those measurements; the program does not discover the physical domain.

## A numerical motion record that closes all terms

Copy `motion_record.template.json` into the directory holding actual raw measurement/calibration files. The four frequency entries in that disabled template originate from software targets; replace/qualify their SI frequencies and frequency errors using the actual timebase. Fill the current configuration, wet equilibrium, rod engagement, writer engagement/removal, preload, sensor-mount and timebase identities. Every intended probe frequency must occur exactly once, with one of three modes: `direct_boss_displacement`, `direct_boss_velocity`, or `bridge_acceleration_with_measured_transfer`. Physical evidence entries need relative paths and SHA256 hashes; the CLI checks those bytes. A matching hash establishes integrity, not laboratory authenticity or correctness of the supplied error budget.

For bridge acceleration, the per-tone peak bound is `(abs(a)+error_a)*(abs(R)+error_R)/(2*pi_lower*(f-error_f))^2`, using exact rational decimal arithmetic and a lower bound on pi. For direct velocity the bound is `(abs(v)+error_v)/(2*pi_lower*(f-error_f))`. Direct displacement uses `abs(x)+error_x`. Complex magnitudes are enclosed from above with rational square roots; phase cancellation is never used to claim more permissible travel. Frequency uncertainty that reaches DC or leaves the observed instrument band blocks the record.

The total envelope adds the sum of all per-tone bounds to **five separately measured or independently justified remainder budgets**: non-tone motion within the observed band; motion above that band; motion below the band and wet-equilibrium drift; drive on/off transients; and instrument-head/mount motion. Each must apply uniformly over the requested command-amplitude domain and full required time interval. A zero is a numerical assertion requiring evidence, not a placeholder for an unknown. Harmonics, intermodulation, ringdown, changing contacts, head vibration and low-frequency drift must fit somewhere in this budget. A least-squares residual RMS cannot automatically become a peak bound, and a filter that rejects a physical component does not prove that component absent. An unknown term returns **BLOCKED**.

A practical in-band procedure retains calibrated boss displacement samples, subtracts the fitted known-tone waveform using a common time origin, and inspects the resulting residual trace over the entire requested interval. Include fitted-coefficient, timing, calibration and subtraction error in the sample-error column. For between-sample peaks, `trace_bound.py` accepts `time_s,displacement_m,displacement_error_m` and an **independently supported uniform physical speed bound**. It returns `max_sample(abs(x)+error)+speed_bound*max_gap/2` for the interval from the first to last sample. For a residual trace, a residual-speed bound may conservatively include the total-motion speed bound plus the sum of known-tone `omega*amplitude` speed bounds. The largest sampled velocity, a decoder range or RMS is not automatically a uniform physical speed bound. Unknown speed, excessive gaps or missing temporal support blocks this route. Its result still applies only to the sensor's qualified physical scope; separate rejected-band motion remains in the motion record.

```bash
python hardware/commissioning/trace_bound.py results/run_001/calibrated_residual.csv --speed-bound-m-per-s YOUR_SUPPORTED_RESIDUAL_SPEED_BOUND --speed-bound-evidence-id YOUR_BOUND_RECORD --max-sample-gap-s YOUR_ALLOWED_GAP --data-origin physical_measurement_declared --configuration-id YOUR_CURRENT_CONFIGURATION --output results/run_001/residual_peak_bound.json
```

For amplitude mapping, choose `measured_reference_only` to qualify only the command actually measured. This is the useful first result; do not invent a scaling law merely to obtain a larger allowable number. After independently checking multiple amplitudes, the alternative `uniform_linear_envelope_declared` scales the fundamental envelope by `p/p_reference*(1+relative_gain_error_upper)` over a declared amplitude interval. The gain-error term must cover waveform quantization, nonlinear changes and state/preload variation left in the intended domain. Remainder budgets remain uniform constants over that interval. The program solves the resulting inequality for the largest supported digital peak within that interval; it never extrapolates beyond it. A new waveform family, frequency mixture, gain setting, specimen or unqualified write invalidates reuse even if its digital peak matches.

Run the actual completed record with:

```bash
python hardware/commissioning/motion.py results/motion_run_001/motion.json --configuration-id YOUR_CURRENT_CONFIGURATION --digital-peak YOUR_PLANNED_PEAK --output results/motion_run_001/motion_receipt.json
```

Only `WITHIN_LIMIT_CONDITIONAL_ON_DECLARED_EVIDENCE` denotes a complete physical-declaration calculation. `SYNTHETIC_WITHIN_LIMIT` remains an assigned test. `EXCEEDS_DECLARED_MOTION_LIMIT` and `BLOCKED` do not yield a qualifying peak for execution. Even a complete result is an offline witness under its recorded conditions, not automatic actuation permission. Exact rational values drive the inequality; `*_display` fields are approximate conveniences.

## Installed writer force and plate-position calibration

Use the **installed** cell, conditioner, external filters, T7 range/resolution/scan order, cable, plate optical target and mounting. Keep the water rod disconnected and use the mechanics-approved initial force/travel envelope. Remove the clay/load-specific contact when qualifying the measurement chain where the mechanical fixture allows it; document any retained fixture force. The displacement reference must observe the actual moving plate at the deformation plane, not screw travel behind the compliant force cell. Use an independent calibrated bidirectional force reference applied in series along the writer force axis and an independent calibrated dimensional reference over the local stroke. Store their identifiers, calibration evidence and uncertainty interpretation. A known mass requires its gravity convention and alignment; nominal masses or a printed screw pitch are not independent calibration.

**Disconnected-writer force is not clay reaction.** The M03/M04 writer is removable for free acoustic reads. Once its clevis is disconnected, its calibrated load-cell samples describe that writer's unloaded baseline, not force retained inside the clay or a material relaxation curve. No SI conversion, holdout fit or clock alignment changes the measurement port. A task asking for clay-force relaxation after writer removal needs a different physical protocol or a separately instrumented persistent reaction port. Record the engagement state for every row/window, and do not combine free-read acoustic measurements with a detached writer channel under the label of simultaneous clay reaction. The motion/R witness likewise binds its writer-engagement identity.

`writer_references.blank.csv` is a fill-in schedule. Its `planned_reference_SI` column is an instruction, **not data**. Leave the actual `reference_SI` as the independently observed reference value; do not copy the plan blindly. The example schedule develops force at -5, -3, 0, +3 and +5 N and holds out -4, -1, +1 and +4 N. Position develops -250, -150, 0, +150 and +250 micrometres, holding out -200, -50, +50 and +200 micrometres. Each is approached in loading and unloading directions. These are initial-range reference targets, not permission to exceed force/travel limits if reached first. Use the independent reference to enforce commissioning load, not an uncalibrated displayed cell value.

Freeze development/validation level IDs before taking data and preserve the schedule/hash. At each level retain the original voltage/time trace, reference trace/readings, measured room temperature, excitation voltage, approach direction and zero before/after. Begin with an engineering dwell of ten seconds per reference point and inspect the final five seconds; extend the hold if the independently chosen settling/drift budget is not met. That dwell is not a settling certificate. Record a representative raw voltage and a supplied absolute raw-error allowance covering the aggregation, remaining drift, ADC uncertainty and timing/slew effects applicable to that reference row. An average's standard error alone is not that allowance. Do not retare between loading/unloading points. Include repeat zero returns and cable/fixture disturbance checks as additional evidence.

The strict CSV header is shown below. All numerical fields describe actual measurements/bounds; row-level origin is either `physical_reference_measurement_declared` or `synthetic_demo`, and mixing them in one fit is rejected. `settled=true` requires the independent check. `reference_error_SI` and `raw_error_V` are assigned absolute error bounds with their own evidence, not automatically a statistical confidence interval. The uniform physical meaning remains an obligation of the independent calibration review.

```csv
channel,split,level_id,direction,approach,raw_V,reference_SI,reference_error_SI,raw_error_V,temperature_C,excitation_V,settled,reference_evidence_id,data_origin
```

For `force` and `position`, both development and validation must contain positive/negative references and loading/unloading approaches. At least three distinct development levels and a separate held-out level set are required. Each split needs at least four rows; repeat each physical point as necessary to examine repeatability. Nonzero validation reference values and level IDs cannot leak into development. The exact-decimal OLS fit uses development data only. Its affine output is `SI=(raw_V-zero_raw_V)*scale_SI_per_V`. Validation does not retune those coefficients. The report separately exposes signed residuals and `abs(prediction-reference)+reference_error+abs(scale)*raw_error` at every reference point. The bound is computed for the serialized decimal coefficients actually placed in the proposal.

If the E02 TMP36 room sensor is to become the room-temperature source, include optional `channel=temperature_C` rows with `approach=heating` or `cooling`. Use an independent temperature reference adjacent to the sensor in stable dry conditions; the blank schedule develops 10, 20 and 30 degrees Celsius and holds out 15 and 25, in both thermal approaches. The fitter does not require negative Celsius temperatures and does not use nominal 10 mV/degree or a 500 mV intercept. It appends a `raw_temperature_V`/`degC` affine proposal with its own reference IDs and held-out envelope. No 20-degree fallback is supplied. An eventual context source also needs its independent domain, error, clock/filter and freshness qualification; the force/position readout does not automatically promote this extra channel.

```bash
python hardware/commissioning/fit_writer_calibration.py results/writer_cal_001/references.csv --template hardware/readout/writer_calibration.template.json --output results/writer_cal_001/fit_receipt.json --record-output results/writer_cal_001/calibration_proposal.json
```

**A finite held-out envelope is not a continuum error theorem.** The tool detects an assigned uniform budget already contradicted by a measured reference point, but it cannot prove behavior between levels, across time, temperature, excitation, hysteresis, mounting, overload or unseen dynamics. The compatible proposal therefore remains `fit_proposal_not_qualified`, with unresolved fields left unresolved. An independent reviewer must supply a defensible uniform `total_error_SI`, raw/SI domains, direction scope, evidence IDs and all timing/filter/slew terms expected by the readout schema. The total must include raw ADC error once, not again on top of an already inclusive budget. Scope and timing from the supplied readout template are preserved; the fitter does not invent origin, sample-age, filter delay, continuous slew or sensor serials. Only after that review should an operator freeze and enable a separate measured calibration record.

**What remains experimentally open.** There are no physical rows in this release. The tools make the missing quantities explicit and numerically testable. They do not replace the independent instruments, measured bounds or task-success criteria. In particular, a fixed-coefficient standard linear solid still has an incremental FRF independent of its initial internal relaxation coordinate. A qualified motion/calibration record is necessary measurement infrastructure; it does not by itself demonstrate nonvolatile material memory or a novel physical computation.
