## Reproduction and scope

Run `python hardware/mechanics_completion/retainers_guard/build.py`. It regenerates the cut/drill tables and screening receipt using only Python's standard library. OpenSCAD's `rg_part` selects the individual holders, clamp bodies, pin, shoe, lid, hinge parts or driver bracket. Integrators should use the prefixed modules, and should subtract `rg_web_machining` from the original web model; do not overlay new bodies on uncut solid webs. The receipt checks nominal clearances and reports conditional bar/pin loads. Friction, clamp strength, sheet impact behaviour, assembled mass, sensor conversion and physical computing remain unmeasured. No purchase, fabrication, calibration or hardware command was performed.
