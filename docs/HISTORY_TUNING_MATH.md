# What the first clay-history tuning experiment can establish

The relevant mathematical object is an action-relevant difference between possible material states. For a quadratic task `z=z0+N*theta+D*a` with loss `||z-goal||_W^2+a^T R a` and positive-definite unconstrained Hessian `D^T W D+R`, the optimum changes under a memory perturbation delta exactly when `D^T W N delta` is nonzero. An observable component can lie in this action nullspace. A force sensor that perfectly identifies it then supplies no tuning benefit.

In a frozen linear system, subtracting the corresponding unprobed baseline removes the initial-state contribution: the incremental response is the convolution of the input with the operators. Thus modal poles and baseline-subtracted transfer features do not identify initial memory. Raw transients and absolute baselines may still contain it. The existing SLS force memory therefore remains a mandatory negative control for an unqualified claim of changed modal tuning. A useful pitch effect needs an identified coupling through tension, geometry, contact, preload or state-dependent stiffness, or a separately defined transient outcome.

For the SLS hold, force contrast is `k1*abs(delta_z0)*exp(-t/tau)`. Distinguishability against bounded force error can expire as that contrast falls below the separation requirement. This is a force-memory readout deadline, not evidence that the best musical action differs. `evaluation.observability` exposes exact task/action witnesses, while `computing.memory` bounds the finite hold.

The evaluation uses actual post-action pitch outcomes from freshly prepared randomized policy episodes. It never assumes an ideal 5-cent action produces exactly 5 cents of future change. The measured action achievement and later target error have separate records. A matching write label or predicted history does not replace that outcome.

There is a separate intervention-to-action gate. Under no effect of H0 versus H1 on a fixed constant action, equal failure probabilities p give discordance probability 2p(1−p)≤1/2, provided the two fresh preparations are conditionally independent. Count a unit only if its constant-policy outcomes are definitely discordant, its actual Fusion actions differ across histories, and both actual Fusion outcomes succeed. This event is a subset of discordance, so its count is dominated by Bin(n,1/2) across independent units, even with heterogeneous p. An exact upper tail supplies the sixth predeclared test. Ambiguous units remain in the denominator as non-events. Equal marginal probabilities without within-block preparation independence would be insufficient.

For each independent confirmation unit, define the conservative improvement `D=baseline_lower_loss-policy_upper_loss`, bounded in[-1,1]. Under independent units and fixed policies/horizon, a one-sided null mean at most delta has tail upper bound `exp(-n*(mean(D)-delta)^2/2)` when the observed mean exceeds delta. The statistics module evaluates an upper rational enclosure, never a rounded-down probability. It allocates the familywise alpha before testing. This is a conservative classical result, not new statistical theory; see [Hoeffding 1963](https://doi.org/10.1080/01621459.1963.10500830).

For a noninferiority difference D in[-1,1], `E[D] <= P(D>0)`. Counting every positive conservative upper difference as a worsening block gives a sufficient binomial noninferiority criterion, under the explicitly stronger common-probability assumption. It is not equivalent to a general mean-difference test. Likewise bounding the reference-condition gain probability below 0.1 bounds its mean gain below 0.1. A separately supported connected gain above 0.1 then establishes a positive condition interaction; it does not certify a 10-point interaction.

Shared days or cartridges can violate the independent-unit premise. The evaluator merges their transitive connected components rather than counting every waveform or repeated trial. Such merging cannot prove the remaining components independent; qualified sampling and preparation remain experimental obligations. Confirmation cannot overlap the development cartridges or days, and feature windows must precede decisions under the declared clock bound.

Cost selection remains a decision-region/experimental-design problem with established predecessors, including [Javdani et al. 2014](https://proceedings.mlr.press/v33/javdani14.html). The exact solver's finite cover proof is a model-level statement. A physical cost claim requires actual omitted protocols, complete cost accounting, and held-out noninferiority. Discarding recorded features, overlooking reset cost or omitting waiting time cannot demonstrate a reduction.

The four synthetic fixtures separate the essential logical cases. The coupled fixture explicitly stipulates an unobserved retained-state contribution to future pitch; it can pass the registered statistical pattern, while remaining nonphysical evidence. The no-task-coupling fixture retains observable state but has one common best action. The unobservable fixture has different useful actions without informative measurements. A fourth fixture offers predictable nuisance information but no write-history effect. All three null cases must return NOT_DEMONSTRATED. None establishes autonomous clay computation or a general advantage over a digital estimator given the same information.
