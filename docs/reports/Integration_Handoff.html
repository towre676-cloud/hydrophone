The first issue the combined design must resolve

A change of hidden material memory need not change the incremental audio transfer response. This is a model-level warning about the chosen observable, not a claim that hydrophones or raw audio can never reveal memory. For a passive standard-linear-solid example, use material deformation e in metres, hidden memory z in metres, and force F in newtons:

F = k₀e + k₁(e−z),   ż=(e−z)/τ
E = ½k₀e² + ½k₁(e−z)²
Ė = Fė − (k₁/τ)(e−z)².

Positive k₀,k₁,τ make the element passive. Its incremental stiffness is K(s)=k₀+k₁τs/(1+τs), independent of the initial memory z. Two histories can therefore have the same incremental transfer features and different absolute force at the same present deformation. More generally, subtracting the unprobed baseline from a frozen linear system removes its initial-state contribution. Raw baselines and transients can still contain the missing information.

This makes the slow plunger essential to the first experiment. Preserve synchronized force and displacement alongside the string, bridge-vibration, and hydrophone waveforms. Do not retain only normalized spectra or transfer estimates. The experiment should ask which combination actually detects the deliberately prepared material difference.

Do not equate the plunger with the bridge

The actual mechanism needs a calibrated mapping between plunger stroke, bridge motion, and material deformation. Locally one possible model is e=γq+βp, with bridge coordinate q and plunger coordinate p. The conjugate forces become f_bridge=γF and f_plunger=βF. The energy identity then includes both work inputs. The geometry coefficients, diaphragm pressure transfer, and any preload-to-string-tension coupling remain unidentified. They cannot be supplied merely by naming the components.

The included synthetic example uses an ideal direct material-deformation coordinate. It does not establish that β=1 or that any chosen γ fits the real frame. Force and displacement must refer to the same epoch. A finite plunger movement or averaging window requires propagation of memory evolution and timing uncertainty; the provided force bounds are an instantaneous t=0 snapshot.

The adapter changes that make the parallel work meet

Different quantities keep their native units. The original Fusion example used one symmetric scalar error radius. The new adapter accepts a separate closed interval for every feature under every hypothesis. Force, displacement, pressure, and dimensionless response features can therefore coexist without being silently added or assigned a shared numerical tolerance.

One physical acquisition is charged once. A single pluck can supply string, bridge, and hydrophone features together. The adapter groups these features under one acquisition protocol and selects protocol groups. Counting every channel as a separate experiment would distort the comparison. Shared setup, reset, and calibration overhead must either be included or represented by complete acquisition bundles before cost claims are made.

The runtime consumes an actual transcript. It filters hypotheses using observed feature values, checks matching units and declared calibration/clock identifiers, and returns their common acceptable actions. Matching identifier strings establishes metadata consistency only. It cannot prove a calibration was valid or clocks were synchronized. This version explicitly reports physical readiness as false and rejects unsupported claims of measured-and-validated evidence.

Unknown evidence remains unknown. Action evaluations are PASS_WITH_BOUND, FAIL_WITH_BOUND, or UNRESOLVED. Only passes enter the acceptable-action intersection. A missing interval blocks the input. An empty intersection with unresolved actions means no certified action with current evidence. It does not prove the hardware is incapable of the task.

For an incompatible hypothesis collection S, an acquisition excludes S if at least one of its feature coordinates has no common possible value across S. The grouped solver and a separate closed-interval arrangement enumeration agree on all 16 added panel cases. Additional checks reject unit mismatch, clock-identifier mismatch, missing bounds, missing grouped features, nonfinite/float input, and an unsupported physical-evidence claim. The original 600 checks remain available unchanged.

The first shared physical experiment

The hardware session should define two repeatable preparation histories, a common observed geometry, and the reset or replicate semantics. Record the preparation order, hold time, environment, commanded excitation, and observed excitation. A reset must not silently erase the memory difference being tested. If probing changes the state, model the complete sequence rather than combining independent-looking features from incompatible histories.

For each prepared condition, acquire the slow force/displacement record and the raw responses from the string, direct-vibration, and water paths. Use actual sensor bandwidths and a declared synchronization bound. Sensor models and sampling rates remain unset in the acquisition draft because the current drawings and electronics plan have not yet supplied them. Hydrophone volts become pascals only after a qualified pressure calibration.

Freeze the diagnostic task and tolerances before selecting the panel. Compare transfer-only features, slow mechanical features, and the complete grouped acquisition. Keep confirmation trials or preparation histories separate from those used for calibration and selection. Report total acquisition, reset, calibration, computation, and verification cost. The first useful result may be a confirmed observability limitation or a finding that the full sensor set is necessary. A visually unified object does not establish a computing or sensor-reduction advantage by itself.
