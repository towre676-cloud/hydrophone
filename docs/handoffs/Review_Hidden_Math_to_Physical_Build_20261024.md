The shared task core is `experiments/clay_tuning_v1/contract.json`. The executable evaluator is `python -m evaluation`; the core is a specification, with hardware qualification and prospective registration still required. This revision incorporates the physical workstream at commit `4ed13aacc6c575a3e97b37949a78ec39e4451e6e`, preserving its M03 build and acquisition code.

The smallest action menu is HOLD or manually raise E4 by 5 cents toward the recovered Gen2 `hex_nat` target of 326.759563456652 Hz. Score the independent future outcome against a 2 cent tolerance, with a separately validated pitch error bound no greater than 1 cent. Action achievement has its own uncertainty and 0.5 cent tolerance. The task does not assume an ideal retune response.

H0 and H1 last 21 seconds and end at time zero. H0 uses one half-stroke cycle after 16 seconds of padding; H1 uses five full-stroke cycles. Both end with one second of rest. An independent mechanical qualification supplies stroke and force limits within M03 provisional ceilings of 0.25 mm and 5 N. The separate dynamic diaphragm motion qualification remains required within the provisional 10 micrometre ceiling. This mathematical contract does not release combined hardware operation.

Every arm receives the same qualified E4 pitch pluck at time zero and a common free-decay pitch readout during 0.10–1.00 seconds. Slow features occupy 1–2 seconds. The full protocol uses the fixed four-tone command at 2–4 seconds; the reduced protocol omits it. Decision is due by 5 seconds, manual action occupies 5–17 seconds, and an independent qualified E4 pluck/readout occupies 18–20 seconds. Register the pluck/read disturbance and estimator qualification. A driven fixed-frequency sinusoid cannot supply natural string pitch by simply reading its dominant frequency.

The core defines the exact slow averaging windows and E4 electrical-loopback channel-ratio features. Bind the extractor implementation and clock/filter corrections before fitting development data. Implement the episode-ledger adapter from calibrated raw records to these fields, keeping actual window indices, setup records and independent outcome lineage. The existing byte auditor checks source hashes and declared recording quality; it does not replay or qualify a pitch estimator, prove laboratory authenticity or establish causal exchangeability. Raw extraction and installed qualification remain physical-session obligations.

Register different command hashes for full and reduced protocols. Keep observed electrical loopback for both, and verify actual probe presence/omission in the qualified extractor. The evaluator checks the appropriate command file hash, preventing a reduced arm from substituting the full command. The common pitch plucks and slow measurements still count toward reduced-arm acquisition cost.

Use connected clay, rod-disconnected clay and a qualified reference cartridge. Record geometry, preload, indexed water depth/temperature, gain, sensor mounts and reader disturbance as required by the physical interface. Rod removal changes loading; it is a pathway diagnostic. Reference matching and fresh, exchangeable preparations are assumptions to qualify, not consequences of a filename.

Development uses randomized, separately prepared actual-action trials. Freeze predictors, normalization, source hashes and the randomized confirmation schedule before confirmation. Confirmation has 64 independent units, each with 36 condition/history/policy episodes. Record actual per-episode cartridge IDs, including distinct reference cartridges. Blocks sharing a day or any clay/reference cartridge merge. A short commissioning pilot remains descriptive. A policy gets no same-episode counterfactual outcome table.

The primary verdict requires improvement beyond 10 percentage points against memoryless and preparation-log baselines, a reference guard, and a history-linked action-success gate. The same-measurement digital predictor is intentionally identical to Fusion full. The sixth gate rejects useful prediction that comes from a nuisance unchanged by H0/H1. All inferential guarantees remain conditional on the registered preparation and sampling assumptions.

Fixed outcome epochs require waiting through an omitted probe. This v1 therefore cannot claim total elapsed-time savings from that omission. The evaluator keeps acquisition, waiting, reset, calibration, computation, action and verification in the cost ledger and returns NOT_DEMONSTRATED for the synthetic fixed-wait case. A later throughput, energy or adaptive-time task needs a distinct registered contract and endpoint.

Physical scoring takes a record root with hash-bound `fusion.run/1`, pre-action feature and independent outcome JSON files. Failed acquisitions/actions remain assigned failures through `fusion.failed-episode/1` logs. Calibration, pitch/pluck qualification, synchronization, dynamic-read qualification, reference matching and command hashes are unfilled in `hardware_binding_template.json`; do not replace them with synthetic IDs. If manual timings or coupling cannot be qualified, revise and register a new core before confirmation, or conclude that this experiment does not demonstrate useful material information.

Within a block, connected and rod-disconnected episodes retain the same actual clay cartridge across histories and policies; the reference has its own fixed identity. Reusing one reference cartridge across all 64 planned blocks merges all of them into one independent unit, so that pilot cannot certify this confirmation criterion. Distinct labels must never stand in for distinct specimens.
