# Performed music statistical priors

This pipeline downloaded and parsed actual performed MIDI from ATEPP 1.2 and ASAP. It processed **12,741 performance files and 35,530,748 completed note records**, including **49 named pianists**. There are **27 canonical composers** after the explicit surname/full-name alias mapping. The sources are piano performances; this is not a corpus of orchestra recordings and no orchestral neural model was trained.

ATEPP 1.2 provides 11,674 metadata-linked automatic MIDI transcriptions of recorded performances, covering 49 named pianists and 25 composers. Its official repository is <https://github.com/tangjjbetsy/ATEPP>, pinned metadata revision `088fb434ec1687d934282be1737bfe2518ea55cd`. The release archive contains mangled Unicode directory names for 2,008 metadata paths; unchanged, unique numeric performance filenames resolve their identity without guessing the musician or work. The supplied archive also contains extra MIDI files that are not in the version-1.2 metadata; those are not silently added. Source license: **CC BY 4.0**. Cite Zhang, Tang, Rafee, Dixon and Fazekas, “ATEPP: A Dataset of Automatically Transcribed Expressive Piano Performance,” ISMIR 2022. These are transcriptions, whose note and velocity estimates can be wrong; they are not original audio or measurements of key force.

ASAP contributes 1,067 performed MIDI files with aligned beat annotations from <https://github.com/fosfrancesco/asap-dataset>, pinned revision `afc815c75c42e83a79c03feb6da8a35e77d4c6b8`. Its current metadata has 16 composer labels. Distinct human identities are not inferred from performance filenames. Source license: **CC BY-NC-SA 4.0**. Cite Foscarin, McLeod, Rigaux, Jacquemard and Sakai, “ASAP: A Dataset of Aligned Scores and Performances for Piano Transcription,” ISMIR 2020. The source manifests retain these different licenses and the full raw datasets are not redistributed here.

`performance_index.csv.gz` is a deterministic compressed per-file analysis index, retaining source path, composition, named performer where supplied, SHA256, note count, descriptive measurements, quality flag, split and eligibility. All 12,741 files parsed; three exact-byte duplicates are excluded from prior fitting. Raw archives stay under `results/corpora`. Downloaded archive and metadata hashes are recorded in `performance_sources.json`.

The fixed split hashes `composer|work` and reserves hash residue zero modulo five as holdout. Within each source, all performances of that work receive the same split. ATEPP records flagged low quality, background noise, corrupted or applause are excluded from fitting. **8,064 performances and 21,654,108 note records remain in the fit set**, with all 49 named pianists still represented. The 2,393 held-out performance records are retained for later testing; no listening-quality improvement or predictive generalization result is claimed from this split alone. Cross-source work aliases are not used as a joint train/test benchmark.

Dynamics are first summarized per performance, then given equal work weight within each named pianist and equal pianist weight. Timing is similarly balanced by ASAP work and composer. The velocity IQR prior is 21 MIDI units and the 5th-to-95th percentile range prior is 48 units. Global beat-interval CV is 0.3203 and includes written tempo changes, fermatas and form. After division by a centered nine-beat running median, local CV is 0.2242. The robust local median absolute deviation divided by the median is **0.05317**, without Gaussian rescaling. It is a measured prior scale for an explicitly authored orchestral expression mapping, not proof of expressive orchestral performance.

The melodic gate statistic is an upper-note onset-cluster key-release proxy. Piano pedal sustain and bow/breath articulation are not inferred from it. Orchestral articulation stays explicitly authored. The performance engine records the measured prior and its bounded mapping in each output score so a listener can distinguish measured corpus statistics, composition decisions and rendering.

To fetch byte-pinned inputs and reproduce the full analysis, run `python -m symphony.performance_data --download --workers 4`. It downloads approximately 287.3 MB including metadata, verifies every source file against the recorded SHA256 and regenerates the compact profile/index. `python -m unittest discover -s tests -p test_symphony_performance_data.py` runs the MIDI/annotation parser tests without network access.
